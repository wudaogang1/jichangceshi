# 关于本站：测评方法、更新规则与推广披露

机场测试（jichangceshi.com）整理代理订阅、节点测速和客户端使用信息。本站的目标不是给出一个永久有效的“第一名”，而是让读者看清数据来自哪里、哪些项目已经核对、哪些结论仍需要用自己的设备和网络验证。

## 信息来源与证据分级

文章中的信息按以下方式区分：

| 类型 | 可以说明什么 | 不能直接说明什么 |
| --- | --- | --- |
| 已登录页面或结算页记录 | 查看当时的套餐、价格、流量、规则和后台功能 | 未来价格、长期稳定性或实际退款结果 |
| 节点状态页面快照 | 页面检测时显示的在线或离线状态 | 用户所在地的延迟、丢包、带宽和晚高峰体验 |
| 服务商页面说明 | 服务商公开宣称的线路、带宽、解锁或设备支持 | 独立实测已经证明这些宣传成立 |
| 本站计算与比较 | 在明确假设下换算月均价格或单位流量成本 | 未披露倍率、续费、退款和有效期后的真实总成本 |
| 用户自行测试 | 特定设备、宽带、地区和时段下的实际体验 | 对所有用户或所有时间段的普遍保证 |

涉及速度、解锁、隐私、日志或退款时，如果没有可重复验证的证据，文章会明确标注为“尚未独立验证”，不会把宣传文案改写成测评结论。

## 测评流程

单项测评优先检查以下内容：

1. 套餐价格、流量、有效期和重置方式；
2. 节点地区、页面状态、协议和流量倍率；
3. Windows、macOS、Android、iOS 及路由器兼容性；
4. 自动续费、设备限制、退款、工单和账户安全规则；
5. 页面信息是否存在互相冲突或缺失；
6. 首次购买后应完成的 24—48 小时真实任务测试。

测速建议使用固定设备、固定宽带和固定样本节点，分别记录白天与晚高峰的延迟、丢包、抖动、下载和真实任务表现。完整步骤见[机场测速方法](/posts/airport-speed-test.html)。

## 更新与纠错

每篇文章会显示首次发布日期和最后更新时间。只有套餐、规则、证据或正文发生实质变化时才更新日期，不会仅为了制造“新鲜”修改时间。

价格、节点和活动可能随时变化。发现数据过期、链接失效或事实错误时，可以通过 [GitHub Issues](https://github.com/wudaogang1/jichangceshi/issues) 提交页面地址、具体段落和可核对证据。收到信息后，本站会重新核查；无法独立确认的内容会保留不确定性说明。

## 推广链接披露

部分注册或购买链接包含邀请参数，站长可能因用户通过链接注册或购买而获得推广收益。包含推广关系的外链会使用 `sponsored` 和 `nofollow` 标记，并在相关页面附近披露。

推广合作不应替代证据。文章的价格表、优缺点、风险提示和未验证项目仍按同一套方法记录；没有单项核查资料的服务，不会仅因为存在推广链接就进入比较结论。

## 使用与安全说明

本站不提供网络线路，也不代替服务商履行订单、退款或技术支持。网络服务的合法性和可用性取决于所在地、用途及适用规则；购买和使用前，请确认符合当地法律法规，并阅读服务商的隐私政策与使用条款。

订阅链接通常等同于访问凭据。不要把链接、二维码或包含订阅信息的截图发送到公开群组或上传到代码仓库。发生泄露时，请参考[订阅链接安全指南](/posts/subscription-security.html)。
