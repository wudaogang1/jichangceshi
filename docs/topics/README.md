# 机场、翻墙、VPN、加速器有什么区别？

“机场”“翻墙”“VPN”和“加速器”在中文网络讨论中经常指向相近需求，但它们并不是同一层级的概念。**翻墙描述目的或行为，VPN 是一种网络技术与产品形态，机场通常指代理订阅服务，加速器则是按使用场景包装的网络优化产品。**

如果不先分清这些词，很容易把客户端当成线路、把游戏加速器当成全局代理，或者因为产品名称里写着“VPN”就默认它具备完整的隐私保护能力。

## 四类关键词快速对照

| 关键词 | 通常指什么 | 用户实际在找什么 | 需要优先核对 |
| --- | --- | --- | --- |
| 机场 | 提供订阅链接和多个代理节点的服务 | 套餐、节点地区、协议、客户端和稳定性 | 运营透明度、倍率、退款、短期实测 |
| 翻墙 | 绕过网络访问限制的通俗说法，不是具体产品 | 工具类型、连接方法、风险和安全注意事项 | 所在地规则、软件来源、账号与订阅安全 |
| VPN | 加密隧道技术，也常指带自有客户端的商业服务 | 隐私、公共网络保护、远程接入或跨地区连接 | 主体、日志政策、客户端权限、断线保护 |
| 加速器 | 针对游戏、跨地区网络或特定应用优化线路的产品 | 降低延迟、减少丢包、改善特定目标的连接 | 加速范围、目标地区、路由方式、是否全局代理 |

## 它们之间是什么关系？

一个机场通常提供“线路和订阅”，Clash Mi、V2RayN、Shadowrocket 等工具负责读取订阅并管理节点。VPN 服务往往把账号、线路和客户端打包在一起。加速器可能使用 VPN 或代理技术，但很多游戏加速器只代理指定游戏流量，不能据此推断它能处理全部网络请求。

因此，产品名称不是可靠判断标准。真正需要确认的是：

1. 流量经过什么类型的连接；
2. 哪些应用或目标地址会被转发；
3. 是否提供完整、持续更新的客户端；
4. 服务方记录哪些账号、设备和连接数据；
5. 发生断线、节点故障或订阅泄露时如何处理。

## 一个更可靠的选择流程

先写下自己要解决的具体问题，例如公共 Wi-Fi 保护、远程办公、游戏延迟、访问特定地区服务或多设备代理。接着只比较能解决这个问题的产品类型，再核对隐私、客户端、退款、设备数和线路说明。

购买后用相同设备、相同宽带和相同时段测试 24—48 小时。记录延迟、丢包、抖动、连接失败与恢复时间，而不是只保留一次最高测速。具体操作可参考[机场测速方法](/posts/airport-speed-test.html)。

## 安全与合规提醒

网络服务的合法性和可用性取决于所在地、用途和适用规则。购买或使用前，应确认符合当地法律法规以及单位、学校或网络提供方的政策。不要把任何工具视为绝对匿名，也不要在来源不明的软件中输入重要账号或授予不必要的设备权限。

订阅链接通常相当于访问凭据。不要公开分享二维码、配置文件或包含订阅地址的截图；如果已经泄露，请参考[订阅链接安全指南](/posts/subscription-security.html)。
