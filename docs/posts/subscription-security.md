# 机场订阅链接泄露怎么办？重置、排查与安全保存指南

机场订阅链接通常包含账户授权信息，泄露后别人可能导入你的节点、消耗流量，甚至通过订阅变化判断账户状态。它应当像密码一样保存。

无论使用机场、VPN、翻墙客户端还是网络加速器，都不应公开账号、订阅、二维码或诊断日志。四类工具的关系与安全边界可参考[基础概念指南](/topics/)。

![订阅链接安全三原则](/images/subscription-security.svg)

## 一、哪些情况说明可能泄露？

- 流量在没有使用时持续下降；
- 后台出现陌生设备、异常更新时间或订阅请求；
- 节点突然频繁失效，或账户被服务商限制；
- 你曾把订阅链接发到公开群聊、截图、工单或代码仓库；
- 复制链接时使用了不明第三方转换网站。

单纯节点变慢不一定代表泄露，也可能是晚高峰负载、倍率变化或服务商调整。需要结合后台流量和设备记录判断。

## 二、发现泄露后的处理顺序

1. 立即停止所有客户端连接；
2. 登录机场后台，寻找“重置订阅”“重置链接”或类似功能；
3. 重新复制新链接，并删除旧配置；
4. 检查机场后台的流量、订单和设备记录；
5. 如果没有重置功能，联系官方工单要求撤销旧订阅；
6. 修改账户密码，并开启可用的二次验证；
7. 观察 24 小时流量是否恢复正常。

重置订阅后，旧链接不应继续使用。不要只在客户端删除配置而不在后台重置，因为旧链接可能仍然有效。

## 三、安全保存方法

- 不把订阅链接放进公开笔记、截图、博客或 Git 仓库；
- 使用密码管理器保存，而不是保存到公共剪贴板同步工具；
- 给不同机场使用不同账户密码；
- 设备转让或维修前删除订阅和客户端缓存；
- 不使用陌生网站把订阅转换成短链接；
- 定期检查流量消耗和后台登录记录。

## 四、客户端使用注意

不要把订阅链接当作普通网址发送给朋友。若需要帮助，截取菜单位置即可，务必遮住完整 URL、二维码、账户邮箱和 token。导入后可以删除系统剪贴板内容，避免被其他应用读取。

## 总结

订阅泄露后的关键是“尽快重置，而不是只删除客户端配置”。购买机场时也应优先选择提供订阅重置、工单支持和明确隐私说明的平台。
