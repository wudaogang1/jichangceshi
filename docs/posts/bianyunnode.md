## 先说结论

边缘节点后台提供购买订阅、节点状态、订单、邀请、工单、流量明细、个人中心和帮助中心等功能。套餐从 ¥15/月的低价试用包，到 ¥200/月的 1000GB 方案，覆盖轻度到重度使用；Android、iOS、macOS 和 Windows 均有客户端下载入口。

**一句话评价：**边缘节点适合先用低价套餐测试，页面信息和后台功能较完整，但长期稳定性、实际速度、隐私和退款规则仍需用户自行核验。

购买前建议确认：

1. 流量倍率是否长期保持 1x；

3. 重置流量包的价格和有效期；
4. 是否自动续费以及如何关闭；
5. 退款规则和特殊套餐限制；
6. 订阅链接泄露后的重置和撤销方式。

### 不足

- 暂未看到 Ping、抖动、丢包和历史可用率数据；
- 页面宣传的 IPLC、峰值速率和解锁能力未被本文独立验证；

- 隐私、日志和退款规则需要购买前进一步确认；
- 节点在线状态不能代表所有地区用户的实际体验。

## 48 小时试用验收清单

1. 在自己的常用设备上安装客户端并导入订阅；
2. 测试香港、日本、新加坡和美国等至少四个地区；
3. 白天和晚高峰分别测试；
4. 播放高清视频、访问常用网站并使用一次 AI 服务；
5. 记录延迟、卡顿、断线、丢包和节点切换恢复时间；
6. 检查流量扣除是否符合 x1 倍率预期；
7. 核对自动续费、重置流量、退款和套餐有效期。

不要只看一次测速结果。连续两天的真实可用率和故障恢复速度，通常比单次峰值速度更有参考价值。

## 常见问题

### 边缘节点机场最低价格是多少？

页面显示的最低起始价是限时体验月付小包 ¥15/月，包含 50GB/月，适合作为首次测试方案。

### 边缘节点有多少节点？

本次查看节点页时显示 72 个在线节点、0 个离线节点。节点数量和状态会变化，不能作为长期稳定性保证。

### 边缘节点支持哪些客户端？

后台提供 Android、iOS、macOS 和 Windows 客户端入口，并提供扫码安装和帮助教程。

### 边缘节点适合直接购买长期套餐吗？

不建议第一次使用就购买长期套餐。更稳妥的方式是先购买 ¥15/月试用套餐，完成常用地区、晚高峰和流量扣除测试后再决定。

### 72 个在线节点代表速度好吗？

不代表。在线状态只能说明页面检测时节点处于可用状态，不能直接推导你的延迟、带宽、丢包和晚高峰体验。

## 最终建议

边缘节点的优势是入门价低、套餐档位较多、节点状态和客户端入口比较完整。首次使用建议从限时体验月付小包开始，重点测试常用地区、晚高峰、实际流量扣除和客户端稳定性。

在没有完成真实测试前，不建议仅凭“不限速”“IPLC”或节点数量直接购买多年套餐。重要账号应开启双重验证，也不要公开分享订阅链接。
