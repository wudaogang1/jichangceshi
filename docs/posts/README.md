## 阅读测评时重点核对

1. 页面数据的查看日期是否仍有参考价值；
2. 服务商宣传与本站已核对内容是否被明确分开；
3. 月付、年付和不限时流量包是否使用同一种计算口径；
4. 在线节点数量是否被误当作速度或长期稳定性；
5. 隐私、退款、日志和自动续费是否有明确规则；
6. 购买入口是否包含推广关系披露。
