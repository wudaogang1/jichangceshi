# Clash Mi 使用方法 2026：下载安装、导入订阅与节点切换教程

Clash Mi 是一款基于 mihomo 内核的 Clash 客户端，适合使用机场订阅的用户。官方主页为 [clashmi.app](https://clashmi.app/)，基本流程可以概括为：安装客户端、添加订阅链接、更新配置、选择节点、开启连接。本文按新手第一次使用的路径整理，菜单名称可能会随版本更新略有变化。

> 本文只介绍客户端的正常配置和排障方法。请确认你的网络使用行为符合所在地法律法规，并从 Clash Mi 官方渠道或机场后台获取软件和订阅链接。不要把订阅链接公开发到群聊、论坛或截图中。

## 官方网站提供了哪些信息？

从 [Clash Mi 官方网站](https://clashmi.app/) 可以确认，Clash Mi 的定位是基于 Mihomo 内核的客户端，支持使用 YAML 配置和机场订阅。官网强调的重点包括：

- 内置 Mihomo（Clash Meta）内核；
- 支持 MetaCubeX 推荐配置；
- 新用户可以直接使用机场订阅，不必手动编写完整配置；
- 项目以 GPL-3.0 开源协议发布；
- 官网提供使用说明和下载入口。

因此，普通用户不需要一开始研究复杂的 YAML 参数。先导入机场提供的兼容订阅，确认连接正常，再根据实际需要了解规则、DNS 和在线面板即可。

## 官方用户手册使用说明：快速开始

官方手册给出的最短使用路径只有两步：

1. 打开应用首页，进入“我的配置”，点击右上角“+”，选择“添加配置链接”，粘贴机场提供的 Clash 或 mihomo 订阅地址并保存。
2. 返回应用首页，滑动或点击连接按钮，等待系统完成 VPN 权限确认即可开始使用。

配置添加成功后，可以在“我的配置”列表查看配置名称、更新时间和流量信息；点击配置旁的更新按钮，可以重新拉取机场的节点和规则。

## 一、Clash Mi 支持哪些设备？

官方用户手册目前列出的系统要求为：iOS 15 及以上、macOS 12 及以上、Android 8 及以上、Windows 10 及以上。软件本身是客户端，不提供节点；要正常连接，还需要机场或自建服务提供的订阅配置。

| 设备 | 安装建议 | 备注 |
| --- | --- | --- |
| iPhone / iPad | App Store 稳定版或 TestFlight 测试版 | 两种版本不能同时安装 |
| Android / HarmonyOS | 官方发布页中的 Android 安装包 | 根据设备架构选择文件 |
| Windows | 官方发布页中的 Windows x64 安装包 | 下载后按系统提示安装 |
| macOS | App Store 或官方提供的版本 | 先核对系统版本要求 |

下载时应优先使用 [Clash Mi 官方主页](https://clashmi.app/) 或[官方用户手册](https://clashmi.app/guide/)里的入口。第三方下载站可能捆绑修改版、过期版本或不明安装包。

## 二、安装 Clash Mi

### iPhone 和 iPad

1. 打开 App Store，搜索 Clash Mi，核对开发者和官方链接。
2. 点击获取并完成安装。
3. 如果使用 TestFlight 测试版，先安装 TestFlight，再按官方邀请链接安装测试版本。
4. 首次启动时允许应用创建 VPN 配置；如果系统弹出 VPN 权限请求，应确认应用来源无误后再允许。

如果 App Store 搜索不到，先检查 Apple ID 所在地区和系统版本。不要使用来源不明的共享账号登录设备，也不要安装陌生描述文件。

### Android 和 HarmonyOS

1. 从官方发布页下载适合设备架构的安装包。
2. 安装前检查文件来源、文件名和系统安全提示。
3. 安装完成后打开应用，并在系统弹窗中允许 VPN 连接权限。
4. 如果安装失败，先卸载旧版或检查系统的应用安装限制，再重新从官方来源下载。

### Windows 和 macOS

1. 从官方发布页下载对应系统版本。
2. 安装完成后启动 Clash Mi。
3. Windows 用户如果遇到安全拦截，应先确认下载来源、签名和文件哈希，再决定是否继续。
4. macOS 用户如遇到系统阻止，先在“系统设置—隐私与安全性”中查看拦截原因，不要直接绕过所有安全检查。

## 三、获取机场订阅链接

订阅链接通常在机场后台的“仪表板”“订阅中心”“一键订阅”或“客户端订阅”页面。Clash Mi 需要的是 Clash、Clash Meta 或兼容 mihomo 的配置链接，不是普通官网地址、注册链接或优惠码。

复制订阅链接时注意以下几点：

- 不要把整段链接发布到公开页面；订阅链接通常等同于账户钥匙。
- 优先复制后台明确标注为 Clash、Clash Meta 或 mihomo 的链接。
- 如果后台提供“复制订阅”“一键导入”或二维码，优先使用官方提供的方式。
- 订阅失效、泄露或异常消耗流量时，应在机场后台重置订阅。

## 四、导入订阅配置

这是 Clash Mi 最核心的一步：

1. 打开 Clash Mi，进入首页的“我的配置”。
2. 点击右上角“+”。
3. 选择“添加配置链接”。
4. 将机场后台复制的订阅链接粘贴到输入框。
5. 填写容易识别的配置名称，例如“我的机场 2026-08”。
6. 保存后回到配置列表，点击刚添加的配置。
7. 等待配置下载完成，确认列表中出现节点或代理组。

![Clash Mi 连接界面](/images/clash-mi-connect.png)

如果机场提供的是本地 YAML 文件，可以在“我的配置”中选择本地文件导入。导入成功后，配置名称、更新时间和节点数量应能正常显示。

## 五、选择节点并开启连接

配置导入成功后，按下面顺序操作：

1. 回到 Clash Mi 首页，确认当前配置已选中。
2. 打开连接按钮，首次使用时允许系统创建 VPN 连接。
3. 进入“代理”或“代理组”页面。
4. 选择一个具体地区或线路；刚开始建议选择距离较近、延迟较低的节点。
5. 返回首页，确认连接状态已变为运行中。
6. 打开浏览器访问几个日常网站，确认连接和 DNS 没有异常。

“节点在线”不代表你的设备一定低延迟。实际体验会受到宽带运营商、地区、时段、节点负载和机场倍率影响。不要只根据节点名称判断速度，建议在白天和晚高峰分别测试。

## 六、代理模式怎么选？

新手通常只需要理解下面三种模式：

| 模式 | 作用 | 建议 |
| --- | --- | --- |
| 规则 | 按配置文件规则决定哪些流量直连、哪些流量代理 | 日常使用优先选择 |
| 全局 | 尽可能让所有流量都经过代理 | 排查规则问题或临时测试 |
| 直连 | 不使用代理 | 测试本地网络或关闭代理 |

一般情况下保持“规则”即可。全局模式可能增加流量消耗，也可能让本地服务、网银或局域网设备访问异常；切换前应知道如何恢复到规则模式。

## 七、更新订阅和切换节点

### 更新订阅

当机场新增节点、删除节点或修改规则后，需要更新配置：

1. 进入“我的配置”。
2. 找到当前配置，点击更新按钮或下拉刷新。
3. 等待更新时间完成。
4. 返回代理组，确认新节点已经出现。

如果更新失败，先检查订阅链接是否完整、网络是否可用，再尝试删除旧配置并重新添加。不要频繁刷新失效链接，以免触发服务商的风控限制。

### 切换节点

1. 打开“代理”或“代理组”。
2. 找到当前使用的代理组。
3. 选择另一个节点。
4. 等待几秒后重新打开网页或应用。
5. 如果仍然无法连接，再切换到其他地区节点。

建议只记录自己的常用节点和晚高峰表现，不要把“测速最快”理解成所有网站都最快。

## 八、在线面板怎么用？

Clash Mi 官方手册说明，应用菜单中提供“面板”入口。如果使用在线面板：

1. 打开 Clash Mi 的“面板”。
2. 进入面板设置页面。
3. 按应用提示填写控制密钥；官方手册说明，面板 `secret` 可在“核心设置”中查看。
4. 只在本机或可信网络中使用面板，不要把面板地址和 secret 一起发给别人。

在线面板适合查看代理组、连接状态和流量信息。普通用户不需要修改复杂 YAML；改动配置前应先备份原配置，避免误删规则导致所有流量走错路径。

## 九、常见问题排查

### 1. 配置导入成功但没有节点

先确认复制的是 Clash/mihomo 订阅，而不是官网链接。然后更新配置并检查机场账户是否有有效套餐、订阅是否过期、流量是否用尽。

### 2. 已连接但网页打不开

依次尝试：切换节点、从全局切回规则、更新配置、关闭其他 VPN 或代理软件。多个代理程序同时运行，容易出现端口冲突和 DNS 冲突。

### 3. 某些应用可以用，另一些应用不能用

这通常与规则、应用自身代理设置或 DNS 有关。先用全局模式做短暂测试；如果全局可用、规则不可用，说明需要检查规则组，而不是反复更换节点。

### 4. 更新订阅提示失败

检查链接是否被截断、是否已重置、网络是否正常，以及机场是否限制请求频率。必要时在机场后台重新复制订阅链接。

### 5. 手机耗电或发热明显

检查是否开启了 TUN、全局代理或大量规则集。日常使用优先采用规则模式，并关闭不需要的后台连接；如果问题持续，先停用配置确认是否由客户端或其他应用造成。

### 6. 如何停止代理？

回到 Clash Mi 首页关闭连接按钮，并在系统 VPN 设置中确认没有其他 VPN 仍处于连接状态。不要只退出应用而不关闭系统 VPN。

## 总结

Clash Mi 的上手重点不是复杂参数，而是“正确的订阅类型、正确的系统权限和正确的代理模式”。新手完成订阅导入后，优先使用规则模式，选择一个稳定节点进行网页和视频测试；出现问题时按“更新配置—切换节点—检查模式—排除其他代理”的顺序排查，通常比盲目修改 YAML 更有效。
