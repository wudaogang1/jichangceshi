# V2RayN使用教程：Windows安装、导入订阅与代理设置

V2RayN 是 Windows 上常见的代理管理客户端。它通常需要配合机场订阅或单条节点使用，软件本身不提供线路。

![客户端导入订阅通用流程](/images/client-import-flow.svg)

## 一、安装前准备

从项目官方发布渠道下载与系统架构匹配的版本，解压到普通用户有权限的目录。不要从网盘、论坛或破解站下载带有额外安装器的版本。

首次运行时检查 Windows Defender 提示、软件来源和文件名。若系统缺少运行库，应优先按项目说明安装，不要随便下载未知 DLL。

## 二、导入机场订阅

1. 登录机场后台，复制 V2RayN、通用订阅或兼容链接。
2. 打开 V2RayN 的订阅管理页面。
3. 新增订阅地址，填写备注并保存。
4. 更新订阅，等待节点列表出现。
5. 在节点列表中选择地区和线路。

如果机场提供的是 Clash 格式，不一定能直接被所有 V2RayN 版本识别，应以机场页面明确标注的格式为准。

## 三、代理设置

在系统托盘中找到 V2RayN 图标，选择代理模式。常用模式包括自动配置、PAC、全局或不启用代理。日常使用优先采用规则或 PAC；临时排查某个网站时，可以短暂切换全局。

选择节点后，先打开浏览器测试，再测试下载、会议或 AI 服务。不要同时打开多个代理客户端，以免端口和系统代理设置互相覆盖。

## 四、节点更新与排障

- 订阅更新失败：检查链接完整性、账户有效期和网络连接；
- 有节点但无法连接：切换地区，检查系统时间和防火墙；
- 浏览器可用、其他软件不可用：检查软件是否使用系统代理；
- 连接很慢：记录延迟、丢包和时间段，不要只看单次测速；
- 卸载后仍然代理：关闭系统代理和其他 VPN 软件。

## 五、安全建议

订阅链接可能包含账户授权信息，不要公开分享。使用完毕后关闭自动启动、检查系统代理状态，公共电脑不要保存长期订阅。

## 总结

V2RayN 的核心操作是添加订阅、更新节点、选择线路和设置系统代理。遇到故障时先排除多个代理软件冲突，再判断是订阅、节点还是系统代理问题。
