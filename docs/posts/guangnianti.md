# 光年梯机场测评：套餐价格、优惠信息、节点表现、测速等

光年梯（Guangnianti）入门版每月 **¥18，含 110GB**。新用户首单用 `sell75` 打 7.5 折，结算页显示月付 **¥13.50**、年付 **¥120**。另有每月 50GB 的 **¥89 限时年付套餐**，该档本次验券未通过。

**常规套餐目前只支持官方客户端**，暂不提供可导入 Clash 或 Shadowrocket 的通用订阅。设备兼容的话，入门版月付适合先试常用节点。Siilas 的四条晚高峰样本中，下载速度从 **8.22 到 121.46 Mbps**，不同出口差异较大。[查看第三方测速](#光年梯测速与晚高峰表现)

## sell75 优惠码怎么用？

登录后打开「购买订阅」，选好套餐和付款周期。在「有优惠券？」一栏输入 `sell75`，点「兑换」，然后核对「订单总额」。下表列出本次后台核对的三种结果。

| 套餐与周期 | 标价 | 验券结果 |
| --- | ---: | ---: |
| 入门版月付，110GB/月 | ¥18.00 | **¥13.50** |
| 入门版年付，110GB/月 | ¥160.00 | **¥120.00** |
| 限时年付，50GB/月 | ¥89.00 | 不适用，仍为 ¥89.00 |

¥89 限时年付的结算页提示「该订阅无法使用此优惠码」。其他套餐、付款周期及重置流量包的适用情况，以结算页验券结果为准。后台没有核实到优惠截止日期。

### 能用 Clash、Shadowrocket 或路由器吗？

仪表盘虽有「导入订阅」的说明，但本次查看的晋级版账号没有可复制或扫码导入的订阅配置。下载卡片上的二维码是用来下载客户端的。常规套餐请按官方客户端来选。

**¥680/月的独享私人专线**是单独的产品。商品页写有专属配置、订阅和路由器支持，本站未开通验证。如果你需要这类配置，付款前请向客服确认是否兼容你的设备。

## 光年梯测速与晚高峰表现
